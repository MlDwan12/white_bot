# Мини-приложение MAX

Папка называется `docs/`, потому что GitHub Pages публикует только из корня
репозитория или из неё. Содержимое — статика, сборка не нужна: библиотека
MAX Bridge подключается тегом `<script>` с CDN.

Секретов здесь нет и быть не может: токен бота живёт на сервере, а страница
только показывает то, что ей передал клиент MAX.

## Что здесь сейчас

`index.html` — **зонд**, а не готовое приложение. Показывает, что клиент MAX
передал странице при запуске: `platform`, `version`, пользователя, чат,
`start_param` из диплинка и подписанную строку `initData` с кнопкой
копирования.

Зонд нужен один раз — увидеть своими глазами, что платформа кладёт в данные
запуска, прежде чем проектировать конкурсный экран.

## Порядок проверки

1. Pages включены: Settings → Pages → `master` / `/docs`. Адрес —
   `https://mldwan12.github.io/white_bot/`.
2. Зарегистрировать адрес на платформе MAX для партнёров: Чат-боты → бот →
   ⋮ Настройки → поле ссылки мини-приложения → Сохранить. Без регистрации
   кнопка `open_app` отвечает `404 Link not found` — MAX ищет адрес среди
   зарегистрированных приложений.
3. Открыть `https://max.ru/<botName>?startapp=<payload>` и скопировать
   `initData`.
4. Проверить подпись локально:
   `PROBE_TOKEN=<токен бота> node docs/verify-initdata.mjs '<initData>'`

## Серверная часть

Проверка подписи — `src/max/webapp-init-data.ts`, покрыта тестами.
Алгоритм: https://dev.max.ru/docs/webapps/validation
